# Plano de contexto do projeto

Hortus é um diretório demonstrativo para conectar pessoas a hortas comunitárias. O objetivo prioritário é localizar e avaliar possibilidades de participação, com filtros úteis e conteúdo acessível.

Públicos: moradores, responsáveis por hortas, educadores, grupos comunitários e visitantes com diferentes necessidades de acessibilidade.

Restrições: dados iniciais são fictícios; cadastro em HTML estático não sincroniza e não autentica com segurança; não publicar detalhes pessoais nem alegar verificação sem processo real.

Tecnologias: HTML semântico, CSS responsivo e JavaScript nativo. Hospedagem: GitHub Pages para o frontend estático e Supabase para os dados de hortas. A URL pública já existe; o deploy desta versão depende do merge de `release/v2.0` para `main`.

Critério de sucesso: visitante consegue encontrar uma amostra por vários filtros, entender o limite dos dados, e responsáveis conseguem demonstrar o fluxo local de criar/editar cadastro sem transmitir credenciais.
